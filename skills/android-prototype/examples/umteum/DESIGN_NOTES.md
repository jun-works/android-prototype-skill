# 움틈 (가칭) — 디자인 결정 기록

시안: `app.src.html`(원본) → `app.html`(빌드본). 이 문서는 각 결정을 **왜** 그렇게 했는지와, Android로 옮길 때 필요한
수치·API를 기록한다. 흐름이 승인될 때마다 이어서 쓴다.

> 이 폴더는 스킬의 작업 예시다. 첫 실행 흐름이 승인됐다고 가정하고, 승인 후 남기는 기록의 깊이를 보여 준다.

- 상태: **첫 실행 흐름 승인** (예시)
- 진행 방식: 흐름 하나씩 승인받은 뒤 다음 흐름으로 넘어간다
- 영감: [rive.app](https://rive.app) — 빌려온 원리: "캐릭터는 입력에 반응하는 **상태 머신**이다. 입력이 바뀌면 캐릭터가
  다른 상태로 옮겨 가고, 가만히 있을 때도 숨쉬기·깜빡임·시선으로 살아 있다." Rive의 그림이나 에셋은 쓰지 않았다.

## 브리프

- 대상: 습관을 몇 번 만들다 그만둬 본 사람. 연속 기록이 끊기면 죄책감을 느끼고 앱을 지운다.
- 핵심 일: 작은 습관을 매일 체크한다.
- 중요한 순간: 처음 고른 습관을 "내 것"으로 느끼는 순간, 그리고 첫 체크의 보상.
- 앱의 약속: 체크할 때마다 씨앗이 자란다. 하루 빠져도 시들지 않는다(벌주지 않는다).

## 흐름 진행

- [x] 첫 실행: 이름 입력 → 습관 고르기(씨앗 심기) → 첫 체크(첫 싹)
- [ ] 알림 권한·체크 시간 정하기 (Android 13+ 알림 권한 포함) — 씨앗이 "내일 몇 시에 깨워 줄까요?"라고 묻는 장면
- [ ] 오늘(홈) 2일째 이후: 여러 개 체크, 자라는 단계(떡잎 → 본잎 → 꽃봉오리)
- [ ] 습관 상세: 기록 달력, 성장 단계, 수정·쉬어 가기

## 2. 핵심 기법 — 씨앗 상태 머신

씨앗 하나 = SVG 하나(줄기·잎 2장 / 몸통 / 얼굴). 상태는 래퍼 클래스로 바뀌고, 전환 모션은 Web Animations API로 재생한다.

| 축 | 상태 | 표현 |
|---|---|---|
| 기분 | `sleep` → `awake` → `happy` | 감은 눈 + Z(느린 숨 5s) → 뜬 눈(4.4s마다 깜빡임) → ^^ 눈 |
| 성장 | 씨앗 → `sprouted` | 흔들기 → 갈라짐 → 줄기 → 떡잎 2장 |
| 입력 | 포커스, 글자 수, 유효성, 잘못된 제출, 체크 | 깨어남 / 시선 x = -5…+5px / 웃음 / 고개 젓기 / 싹 |

- **숨쉬기**: `scale(1.035, .965)`, 바닥 기준(`transform-origin: 50% 100%`). 씨앗마다 지연을 달리해 동시에 숨쉬지 않게 했다.
- **시선**: 입력한 글자 수를 -5…+5px로 바꿔 얼굴 레이어를 옮긴다(스프링 느낌 `cubic-bezier(.3,1.4,.5,1)`).
- **던지기**(습관 고르기): 봉투 위치에서 흙 자리까지 0.98s. 키프레임 0 → 42%(정점, 회전 200°) → 76%(낙하 가속) →
  88%(착지 찌그러짐 `scale(1.18,.8)`) → 100%. 착지 0.85s에 흙 알갱이 7개가 튄다.
- **빼기**: 0.42s 동안 튀어 올라 작아지며 사라지고, 남은 씨앗들이 FLIP 방식(이전 위치 → 새 위치)으로 작은 점프를 하며 자리를 옮긴다.
- **싹 틔우기**(첫 체크): 0–0.45s 흔들며 깸 → 0.42s 껍질 금(stroke-dashoffset) → 0.54–1.16s 줄기가 자람 →
  0.98·1.08s 떡잎이 `scale(0)→1.18→1`로 펴짐 → 0.38–2.08s 뒤에서 햇빛이 번졌다 사라짐 → 1.65s 웃으며 작게 점프.
- **스틸 / 모션 줄이기**: `App.shot`이나 `App.reducedMotion`이면 모든 전환을 건너뛰고 최종 상태(싹, 웃음)만 보여 준다.

**Android 구현 참고:**
- 캐릭터는 Rive 상태 머신으로 옮기는 것이 가장 자연스럽다(입력: `focused`, `textLength`, `valid`, `rejected`, `checked`).
  디자이너가 Rive 파일을 소유할 수 없으면 Compose로 직접 구현한다.
- Compose 직접 구현: 씨앗은 `ImageVector` 레이어(몸통·얼굴·줄기·잎) + `graphicsLayer`. 숨쉬기는
  `rememberInfiniteTransition`, 던지기는 `Animatable<Offset>` + `keyframes`, 착지 찌그러짐은
  `spring(dampingRatio = 0.5f)`, 줄기는 `PathMeasure`로 경로 일부만 그리기, 떡잎은 `animateFloatAsState(spring)`.
- 흙 알갱이는 `Canvas`에서 수명이 짧은 파티클로 처리하고, 화면을 벗어나면 루프를 멈춘다.
- 시스템 애니메이션 배율이 0(`Settings.Global.ANIMATOR_DURATION_SCALE`)이면 최종 상태로 바로 그린다.

## 3. 화면별 결정

### ① 이름 입력
- 처음엔 씨앗이 자고 있다(Z). 입력 칸을 누르면 깨어나 "앗, 누구세요?", 쓰는 동안 글자 끝을 눈으로 따라오고,
  이름이 맞으면 "지우님, 반가워요!" 하며 웃는다. 비운 채 '다음'을 누르면 고개를 젓는다.
- **이유:** 회색 비활성 버튼 대신 캐릭터 반응으로 상태를 알린다. 첫 화면에서 "이 앱의 씨앗은 나에게 반응한다"는 약속을 보여 준다.
- 1–8자, 한글·영문·숫자. 글자 수 카운터와 도움말은 텍스트로 남겨서 캐릭터 없이도 규칙을 알 수 있다.

### ② 습관 고르기 (씨앗 심기)
- 습관 8개를 크라프트 씨앗 봉투로 보여 주고, 마지막 칸 "직접 쓰기"는 바텀시트로 연다(이름 2–12자, 시간대 칩).
- 고르면 씨앗이 봉투에서 포물선을 그리며 날아가 아래 텃밭에 박힌다. 다시 누르면 튀어나오고 남은 씨앗이 자리를 옮긴다.
- 처음엔 3개까지만 심는다. 4번째를 누르면 봉투가 흔들리고 스낵바로 이유를 알려 준다.
- **이유:** "습관을 고른다"를 "씨앗을 심는다"로 바꾸면 선택이 소유가 된다. 3개 제한은 실패 경험이 있는 사용자에게 "작게 시작하기"를 강제하는 장치다.

### ③ 첫 체크 (첫 싹)
- 텃밭이 화면의 주인공이다. 목록의 체크 버튼이나 씨앗을 직접 눌러도 싹이 튼다. 다시 누르면 체크가 취소된다.
- 아래에 "하루 빠져도 시들지 않아요" 안내를 둔다.
- 첫 실행이 끝난 화면이라 시스템 뒤로 가기로 온보딩에 돌아가지 않는다(`data-no-up`).
- **이유:** 첫 체크의 보상이 이 앱의 전부다. 숫자(1/3) 대신 살아 있는 변화로 보상하고, 연속 기록이 끊길까 하는 걱정에는 먼저 답한다.

## 4. 확정 필요 / 가정한 것

- 앱 이름 "움틈"은 가칭이다.
- 처음 심는 습관은 최대 3개로 잡았다(작게 시작하기). 개수는 바꿀 수 있다.
- "놓친 날에 시들지 않는다"는 정책이 맞는지 확인해야 한다.
- 첫 체크 뒤 하단 내비게이션(오늘/기록/설정)은 다음 흐름에서 정한다.

## 5. 개발 시 데이터·권한 메모

- 이 흐름에는 권한이 없다. 알림(`POST_NOTIFICATIONS`, API 33+)은 다음 흐름에서 이유를 먼저 보여 준 뒤 요청한다.
- 오늘 날짜의 경계(자정)와 시간대 변경은 체크 기록 모델에서 정해야 한다(UTC 저장, 로컬 날짜로 표시).
- 습관별 씨앗 모양·색은 생성 시 고정해서 저장한다(목록 순서가 바뀌어도 같은 씨앗).
